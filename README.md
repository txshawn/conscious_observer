# conscious_observer

[![Alt Text](Zenodo DOI badge)](https://zenodo.org/badge/DOI/10.5281/zenodo.24296810.svg)

Repo for project Conscious Observer, an autonomous embodied system bult to mimic certain mammalian brain mechanics to attempt to simulate consciousness-like behavior patterns. See [ARCHITECTURE_DISCLOSURE.md](https://github.com/txshawn/conscious_observer/blob/main/ARCHITECTURE_DISCLOSURE.md) for detailed information.

This project is released under GPLv3 and CERN-OHL-S v2.0 in order to ensure that no one person or organization can profit from what could potentially become actual digital life.
